## Selected proof

### [PGAI Patient Simulator](https://github.com/varunjose/PGAI-Assignment) — Realtime Voice AI

Built an outbound patient simulator using FastAPI, Twilio Media Streams, and OpenAI Realtime. It runs 12 scenario-specific personas and produces recordings, two-sided transcripts, metadata, event logs, and structured post-call evaluations. The repository includes safety constraints, automated tests, documented tradeoffs, and real assessment artifacts.

### [JobSignal](https://github.com/varunjose/JobsAggregator) — Data Platform & Automation

Built a deployable U.S. job aggregator with public feeds and direct ATS connectors, one canonical schema, source provenance, deduplication, profile-fit scoring, PostgreSQL, a FastAPI service, Docker, CI, and unattended ingestion every two hours.

### [Agentic Real-Time Streaming](https://github.com/varunjose/Agentic-Real-Time-Streaming-System-RL-) — Adaptive Systems

Built a C++/OpenCV live-video system that fragments H.264 over UDP, measures network and QoE signals, and adapts bitrate, FPS, GOP, and resolution using fixed, rule-based, learned, and agentic-hybrid controllers with safety overrides.
